# Stillmark 影迹图片工作台 Windows 预览版

这是自带后端与运行环境的 Windows x64 开发预览便携包，使用时不需要安装 Python、Node.js 或开发依赖。

显示名称为 Stillmark 影迹图片工作台。为兼容既有启动脚本，本版可执行文件仍名为 GalleryTool.exe，配置与数据目录也继续沿用旧名称。该预览包未做代码签名。

1. 将整个 ZIP 解压到可写目录，保留 resources 等文件夹。
2. 双击 GalleryTool.exe。
3. 在“添加图库”中选择本地图片目录。索引在后台建立，已扫描内容可直接浏览。

支持 JPEG、PNG、GIF、WebP、BMP。图片墙使用静态封面，动图在单张查看器播放；单张导航止于当前图包。文件夹标记、抽样、相似分析、完整文件核验和删除结果都在工作台内使用。

用户数据默认位于 %LOCALAPPDATA%\GalleryTool。原图保留在添加的图库目录中。图库和程序可以放在不同磁盘，数据库与缩略图建议放本机 SSD。高级配置可用环境变量 GALLERY_DATA，或相邻 GalleryTool.local.json 的 dataDirectory 字段指定独立数据目录。

关闭窗口会收至系统托盘；在托盘菜单选择“退出”可结束桌面和它自行启动的后端。若复用了外部后台服务，该服务由其启动者单独管理。

替换开发预览前退出旧构建并备份数据目录。将新包解压到另一个目录，再用相同数据目录启动；保留原包用于核查。数据库可能执行向前迁移，回退旧程序时需要使用升级前的备份，不能直接用旧程序打开已升级的数据。

“管理图库”可修改显示名称、重新连接搬迁后的根目录，或将图库移出工作台。相对路径相同的图片保留位置和标记。移出管理会保留原图、索引、缓存与历史记录；重新添加原目录可以恢复。

默认删除移至回收站，失败不会自动改为永久删除。永久删除需要明确确认；请查看逐项结果。相似度只提供线索，整包完全重复结论会核验非图片文件。

当前是 Windows 本地图片预览版。暂不支持 RAW、HEIC、AVIF、压缩包、视频、网络图库或云同步。大图首次派生需要磁盘读取和解码时间，性能取决于素材和硬盘。
