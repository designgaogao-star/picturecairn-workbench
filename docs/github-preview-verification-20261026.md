## 本次修复及证据边界

SQLite 曾在短请求之间关闭全部连接，反复清理和恢复 WAL。缩短等待来放大窗口后，1600 次并发读写出现五次 `SQLITE_BUSY` / `SQLITE_BUSY_RECOVERY`，保留一条空闲连接的对照没有出现。服务现在持有不执行事务的生命周期连接，退出工作结束后显式关闭；连接配置失败也立即释放句柄。两条确定性回归先失败后通过。

缩略图切换 400／800 档位时，旧节点迟到的 load 或 error 曾将新资源复位为加载中。真实图片墙的两个受控回归先失败后通过；完整资源 URL 现在对应独立的状态、观察器与 Blob 生命周期。

分页请求在途时再次收到刷新通知，旧响应曾清掉过期状态，之后没有发出新请求。清单现在记录失效代次，旧结果继续显示为过期内容，可见窗口接着取得新快照。两个受控回归分别验证更新成功，以及后续 503 时保留卡片、两次自动重试与手动恢复；旧实现均失败，修复后与既有场景全部通过。没有增加请求并发、取消每次在途读取或放宽断言。

这些是可复现问题的修复。历史任务列表 500 和远程分页超时没有原始在途时序与异常堆栈，不能仅因症状相近就宣称已经证明同根。
