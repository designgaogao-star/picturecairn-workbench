# 图片工作台开发更新

2026-10-23，本地 Windows x64 开发构建，未发布。该次交付包为 `build-out/20261023-164655/GalleryTool/GalleryTool.exe`，完整验收见 [使用质量验收](review-quality-20261023.md)。

## 本次变化

- 图片墙、图包与目录采用统一工作台；信息、任务和整理操作就近展开。支持跟随系统、浅色、深色外观。
- 方向键、Home/End、PageUp/PageDown 可以直接浏览大图包；跨页按目标加载，保留空格选择、Shift 连选、Enter 查看和返回焦点。
- 刷新、跨动态端口重启和调整窗口宽度保留路由、偏好与浏览位置。菜单、查看器和侧面板按各自层级处理 Escape。
- 快速切换图片时撤销过期的派生订阅，同图仍共享工作；后台扫描、预热和分析继续服从前台 IO 与解码预算。
- NumPy、SciPy 默认在单线程 BLAS 配置下初始化，减少 Windows 上分析任务的 native 线程和提交内存保留；原 pHash 与内容核验算法保持一致。
- 任务保留进度、目标、失败原因及逐项删除结果。完全重复仍使用包含非图片文件的全文件 SHA-256 核验，相似度只作为线索。

## 使用与升级

通过项目根目录的 `启动图库.bat` 打开桌面，`启动图库预览.bat` 打开浏览器。数据目录由 `GALLERY_DATA` 或本机 `runtime.local.json` 决定，原图保留在注册的图库中。

本机入口已指向新包。已打开的旧窗口或外部后台服务继续运行；正常退出桌面、使用 `停止图库服务.bat` 停止旧后台，再启动即可使用更新。程序自身启动的后端随桌面退出。

桌面运行不需要另外安装 Python 或 Node.js。默认删除进入回收站；永久删除仍需要明确确认。`prototype/` 保留为历史参考。
