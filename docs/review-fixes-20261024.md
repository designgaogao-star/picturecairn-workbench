# Review 修复验收：导航索引与桌面退出

2026-10-24，分支 `feat/backend-v2`。本轮处理已确认的两项 P2，未接入 Stillmark 品牌资产，未提交、推送或切换本机运行入口。

## 行为与依据

1. 列表修订前，焦点项位于索引 10；前置插入一项后，它变成索引 11，旧代码按右键仍停在同一项。现在按持久 ID 更新游标与焦点保留节点，并以当前单元格索引导航。新增测试还覆盖删除前置项、重排跨行和改变列数；浏览器移动 keyed DOM 节点引起的失焦会恢复到原资源，主动转移的焦点不被抢回。
2. 退出前保存偏好曾无界等待 `executeJavaScript`。模拟渲染线程阻塞八秒时，旧版约 8.4 秒才退出，等待期间后端仍正常响应。现在偏好读取最多等待 1.5 秒，超时后保留旧文件并继续退出；迟到的读取结果不能写盘。后端仍按既有优雅退出时限结束任务，1.5 秒不是整个应用的退出保证。

## 测试操作偏差

本轮最初运行全量 pytest 时遗漏原生回收排除条件；发现时命令已经结束，两项测试分别将临时文本文件和临时图片送入 Windows 回收站。这违反了本轮“不碰回收站”的约束，未涉及真实图库，也未操作回收站进行清理。

随后将这两项测试统一标记为 `native_recycle`，在 pytest 默认配置排除；只有明确指定该标记才会运行。最终直接运行 pytest 已确认 77 项通过、两项排除。统一验证脚本和文档采用相同默认，防止常规全量验证再次触发原生回收。
