# Stillmark 后端重构实施清单

目标：多本地目录、浏览优先、纯图片，保留整理能力，以类型化接口交给正式前端。

架构：单进程 FastAPI 服务，SQLite WAL 保存权威索引和用户状态；有界线程调度磁盘任务。
Pillow、NumPy、SciPy 负责图像与既有 pHash；Electron 仅提供桌面集成。

- [x] 锁定 Python 3.14 环境，建立目录、图片、任务与接口模型。
- [x] 实现稳定 ID、分页、增量扫描、变更监听和旧数据迁移。
- [x] 实现图片档位、缓存、调度与内存预算。
- [x] 接回标记、抽样、去重、完整内容核验和可控回收。
- [x] 交付 OpenAPI、TypeScript 客户端、模拟数据与可运行原型。
- [x] 完成测试、review、性能核验、实际打包与运行入口切换。

验证使用临时图库；真实图库只做只读测量。旧数据以 SQLite backup 快照保存，原图不迁移。
每个阶段独立 review 和提交。默认由当前会话逐项实施，不额外创建代理任务。

已完成验收，结果与限制见 [后端重构 Review 与验收](review-v2-20261020.md)。前端从 [前端交接](frontend-handoff.md) 接手。
