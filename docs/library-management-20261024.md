# 图库管理闭环交付记录

## 实现

- 显示改名、根目录搬迁后重连、移出管理及重新添加恢复，均以图库 ID 操作。OpenAPI 与 TypeScript schema 已重新生成；204 客户端返回类型为 void。
- SQL 008 仅增加 managed 标记。目录、图包、图片、浏览状态、缓存、操作日志和历史任务不因移出而删除；启动和维护不会自动恢复已移出的图库。
- 重连提交普通对账任务，同相对路径的资源沿用 ID，revision 递增使旧核验过期。有 queued/running/paused/cancelling 的关联任务时返回 409 library_busy；队列满不留下半次换根。
- 每个图库有独立监听停止信号；旧根通知核对当前根与 managed，不能重建旧监听或接受旧通知。未管理图库的图片资源、列表、标记和新任务入口不可访问，包含已命中磁盘缩略图缓存的请求。
- 正式前端的管理菜单、三种对话框和离线重定位入口已接入，沿用现有工作台设计。打开后台任务后可恢复重连草稿；移出最后一个图库清除旧路由，回到添加表单。
