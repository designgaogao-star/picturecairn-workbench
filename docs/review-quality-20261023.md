## 已落实的行为

- 前端卸载取消的缩略图请求能穿过实际 HTTP 中间件，撤销后台订阅。最后一个订阅离开后，排队工作跳过原图读取；等待生成锁、源卷或解码预算时可退出，原生解码/编码在阶段边界响应取消。
- 同图仍按有效订阅者合并。已取消的 executor 项直到被 worker 消费才归还队列名额，不能用连续取消绕过上限；旧工作完成不会误删同键的新工作。取消不写图片错误，并清理未发布的编码临时文件。
- 源文件抛出 `TimeoutError` 时按实际错误返回，不误当作 Future 还在等待。真实回环连接断开测试确认取消实际传到工作线程。
- 图片、图包、文件夹和侧栏主按钮采用单一 Tab 入口。方向键按列移动，Home/End 到首末，PageUp/PageDown 按可视行移动；跨页直接读取目标页，连按以最新目标为准。保留空格、Shift 选择和 Enter 打开。
- 调整列数保留焦点资源，手动滚动后保留墙面锚点。侧栏收起为窄屏时不短暂抢占模态焦点；关闭侧面板时尊重已转移到墙面的焦点；查看器加载中返回有可用的墙面焦点恢复。
- `scripts/verify.ps1` 汇总 Python、Ruff、契约、严格 TS、UI 构建、JS 语法、三个浏览器回归及可选实际桌面/长测。默认排除两个原生回收站探针。正式构建继续只使用 `scripts/build.ps1`。
