## Review 与修正

- 扫描异常和重启清除残留状态；no-scan 同时禁止维护扫描，间隔可配置。待处理扫描按图库合并，运行中的扫描保留一次跟进，目录已消失不报读取失败。
- 注册图库先检查队列容量；非法任务控制统一 409，结束任务保留计数、来源和目标名称。
- 删除前就记录意图；缺失目标逐项 skipped 后继续，离线目标失败且保留索引，取消保留已完成结果；loose 图包在 HTTP 层拒绝。
- 缓存回收只能删除当前 data/derivatives 内的文件，旧缓存路径只清理引用。临时快照测试确认 ID、位置和缓存隔离。
- 分组/图包详情、封面版本、任务筛选分页、相似结果完整分页、图片对图包 ID、独有文件路径、清理证据、结构化错误和 SSE 心跳接入正式前端。
- 缩略图按显示顺序预热，版本 URL 命中 immutable；前端有界 fetch 直接获取错误，移除失败后的第二次资源探测和逐卡封面请求。
- 桌面保存路由 hash，跨动态端口重启仍恢复同一张图片；虚拟列表在窗口缩放时丢弃旧布局的滚动帧，并限制分页范围。
