# PictureCairn 工作台与首次设置体验设计

> 本文是 2026-10-27 长时间运行收口的设计记录。它延续现有 PictureCairn 设计规范，不改变后端契约、持久 ID、分页、虚拟网格或删除语义。

## 目标

让 PictureCairn 从“功能已经能用”变成“长时间使用也可信”：用户打开后能立刻知道当前图库、索引状态和下一步；图片墙在内容少、扫描中、失败和窄屏时仍像完成的产品；后台任务、错误和恢复路径可读、可操作；首次设置像一个有品牌的桌面工作流，而不是裸表单。

## 视觉方向

采用“安静的档案台”方向：纸色/石色工作面、墨色正文、蓝色只负责选择和焦点、朱色只保留在压角印品牌标识。布局保持 Fluent 2 的熟悉密度，以细分隔线、稳定网格和少量强调条建立层级，不引入渐变、玻璃、插画卡片或装饰性动画。

主工作区使用一个紧凑的上下文头：名称、真实路径、索引状态、文件夹/图片计数和继续浏览入口分成可扫描的两行。卡片仍以图片为主，但增加稳定的底部信息带、扫描/离线/失败状态和最近位置标记。空白区域由明确的空状态、扫描进度或轻量统计填充，不能靠随机装饰填满。

首次设置页保留“添加第一个图库”的实际任务，增加品牌承诺、三步说明和本地隐私提示。表单在桌面和窄屏都保持清晰，浏览器仍可手动输入路径，Electron 额外显示选择文件夹按钮。文件选择器继续使用 Windows 原生 UI，页面负责在打开前说明选择目的、返回后显示路径和索引进度。

## 工程边界

- 只修改 `ui/`、必要的 Electron 首次启动文案和文档；不新增控件库，不改变 API。
- 所有新状态来自已有 `Library`、`Group`、`Task` 和 `Review` 类型；没有假造统计值。
- 所有可操作控件保留键盘语义、`aria-label`、焦点样式、加载/禁用/失败状态。
- 页面改动不能增加缩略图请求、预载数量或 DOM 数量；新增摘要只使用已有响应。
- 安装器本轮以“首次设置体验 + 安装器视觉规范/静态原型”交付，不引入未锁定的 Windows 安装打包工具；便携包构建入口保持不变。

## 验收

1. 空图库、扫描中、已完成、离线和读取失败均有明确下一步。
2. 桌面首屏在 1600×1000 和 1280×800 下不出现无意义的裸空白区；390×844 下不横向溢出，按钮可触摸。
3. 添加图库流程在浏览器手输路径、Electron 文件夹选择、失败重试和扫描中返回四种状态下可用。
4. 任务抽屉打开、筛选、刷新、错误重试和关闭不丢失当前浏览位置。
5. 真实临时图库完成图片墙、动图查看器、位置恢复、整理、删除结果和重启恢复验证。
6. 长时间测试使用临时图库与临时数据目录，目标至少运行 8 小时；记录每轮请求、任务、页面错误、进程退出和内存趋势，不为了通过而降低门槛。
