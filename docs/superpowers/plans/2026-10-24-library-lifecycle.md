# 图库管理闭环实施计划

**目标：** 支持修改显示名、重新连接迁移后的根目录、移出管理并恢复，保留原图、持久 ID、浏览记录、缓存与操作日志。

**结构：** 新增图库生命周期服务，复用 Catalog、Tasks、Watcher、Access；管理变更与任务受理共用调度锁，防止换根时仍有旧任务工作。SQLite 第八版迁移仅增加 `managed` 标记；不删除用户数据，不增加新的任务种类。

**技术：** Python/FastAPI/SQLite、现有 Preact/Signals/Lucide、生成的 TypeScript 契约。当前共享分支内顺序实施，不切分支、不提交；品牌资产由另一位设计负责人完成。

## 接口与行为

- `GET /api/v1/libraries/{library_id}` 返回当前受管理的图库；列表只列 `managed=1`。
- `PATCH /api/v1/libraries/{library_id}` 接受非空、最多 120 字符的 `name`，返回图库。仅改显示名及根目录索引名称，不改磁盘目录、不触发扫描。
- `POST /api/v1/libraries/{library_id}/reconnect` 接受 `path`，验证存在、本地、与其他受管理图库不重叠、没有占用该路径的其他图库记录；更新根路径、递增 revision、切换监听，返回 202 的常规 scan 任务。相同相对路径沿用目录、图包、图片 ID。
- `DELETE /api/v1/libraries/{library_id}` 只将 `managed` 置零并停止监听，返回 204。索引、记录、日志与原图保留；原路径重新 POST 注册时恢复原 ID 并启动对账。
- 重连和移出之前若存在 queued/running/paused/cancelling 的关联任务则返回 409，界面引导等候或在任务面板取消。注册/重连在改变索引状态之前检查队列容量；失败不留下半次路径更新。
- 未管理图库的浏览、图片、标记及新任务入口返回不可用；任务历史与操作日志仍可读。监听和维护扫描只操作受管理图库，旧根的延迟通知不能重新登记旧监听。

## 验收限制

只使用临时图库与临时数据目录，不访问真实数据库，不执行回收探针。重连表示用户主动选择同一图库迁移后的根目录，不自动识别或移动文件，不扩展到网络图库。旧核验结论因 revision 递增失效，完全重复仍须读取全部文件重新核验。
