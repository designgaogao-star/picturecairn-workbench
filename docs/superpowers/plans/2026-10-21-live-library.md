# 正式图库落地计划

**目标：** 关闭阻碍正式使用的正确性问题，补齐大图库浏览所需接口，将 F:/图库 的全部受支持图片加载到正式桌面程序。

**依据：** 用户明确要求持续推进到落地并加载全部图片，沿用既定 V2 架构和 UI；本次直接在当前会话执行。

**方案：** 保留现有 ID 和浏览记录，以 SQLite backup API 从旧数据目录建立独立的正式运行目录，原目录只读。先在临时图库复现并修复扫描、任务及删除问题，再补齐详情、封面、状态与证据接口。图像按需加载，有界预览与分页不因全量索引而取消。

- [x] 修正 `gallery/jobs.py`、`service.py`、`indexer.py`、`organize.py`、`app.py`；删除始终逐项留记录，扫描调度合并同一图库的待处理工作。
- [x] 临时数据运行回归，排除原生回收站操作，不在真实图库执行删除测试。
