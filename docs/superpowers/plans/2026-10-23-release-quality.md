# GalleryTool 使用质量与版本交付排期

目标：完成慢盘加载、长期运行、图片墙键盘浏览和版本收口四项工作，验收后交付可运行桌面包。沿用图片工作台设计与现有技术栈，不扩展产品范围，不提交未经明确授权的 Git 提交。

## 阶段 1：加载测量与修复

- [x] 用当前已验收的 `20261023-012543` 包作为基线；在 F: 机械盘创建独立临时生成素材，数据和缓存放 C:。
- [x] 测量派生首次请求、预热/扫描竞争、健康和清单延迟、RSS 和进程 IO。物理冷读与操作系统缓存未清空的测量分开说明，不把进程 IO 当作物理 IO。
- [x] 事件控制测试验证过期请求、同图共享、排队和运行中取消是否释放预算；有可复现问题再修改图片链路。
- [x] 前端取消后，未开始的工作不得读原图；已开始的原生解码不强行中止，后续可取消阶段让出资源。相同缓存键仍按有效订阅者合并。
- [x] 修改后使用相同素材复测，图像输出摘要一致；健康 P95 <50ms、100 条清单 P95 <100ms、热缩略图 P95 <50ms。

## 阶段 2：键盘浏览

- [x] 虚拟图片/图包/文件夹网格提供一个可 Tab 进入的主入口；方向键按真实列数移动，Home/End 到首末，PageUp/PageDown 按可视行移动。
- [x] 缺页按目标页读取，不枚举中间页；快速按键以最终目标为准，不抢菜单、表单、侧面板和查看器按键。
- [x] 保留空格选择、Shift 选择、Enter 打开；列表边界停住，调整列数保留当前焦点资源。侧栏的一列导航沿用网格规则。
- [x] 自动化覆盖桌面与 390×844、跨分页/虚拟行、末页和快速切换、图包边界、返回焦点与既有选择。

## 阶段 3：实际桌面长期测试

- [x] 在最终构建产物上连续运行至少 60 分钟，用临时图库与数据目录，循环滚动、切图、切换范围和后台预热/扫描/分析/任务控制。
- [x] 定期记录每个所属进程的 PID、角色、RSS/私有内存、句柄、线程、进程 IO；渲染器 JS 堆、DOM、请求和任务状态另记录。退出后确认本轮所属进程全部结束。
- [x] 验收：无崩溃和未处理异常，无挂起任务或请求积压；缓存不超过配置预算；采样后段的稳定工作负载无持续内存/句柄增长。若发现增长，定位修复并重新跑满 60 分钟。
- [x] 日志与每轮采样即时写入忽略的 output；时间不压缩，不以短测代替长测。
