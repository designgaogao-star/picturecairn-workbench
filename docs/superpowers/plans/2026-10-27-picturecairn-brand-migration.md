# PictureCairn 品牌迁移实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将产品从 `Stillmark 影迹图片工作台` 统一更名为 `PictureCairn 影标图片工作台`，保留“压角印”图形逻辑和现有用户数据、API、程序文件兼容性。

**Architecture:** 品牌显示名称、转曲字标、Windows 元数据和文档统一使用 PictureCairn；`GalleryTool.exe`、`GalleryTool.local.json`、`GALLERY_DATA`、`%LOCALAPPDATA%\GalleryTool`、`gt.*` 本地存储键和 API 路径继续保留。品牌源目录迁移到 `docs/brand/picturecairn`，通过现有生成脚本重新生成 SVG、PNG、ICO 和托盘位图。

**Tech Stack:** Python 3.14、Pillow、FontTools/HarfBuzz、Node.js、Electron、Preact、Vite、PowerShell、pytest、Ruff。
